# 操作ガイド(OPERATION)

本体の物理ボタン操作とメニュー構成の早見表です。セットアップ手順自体は [README](../README.md#セットアップ手順) を参照してください。

## ボタン対応表

| ボタン | PLAY 画面 | メニュー画面 |
| :--- | :--- | :--- |
| **↑ / ↓** (GPIO 22 / 27) | 音量 UP / DOWN | カーソル移動 |
| **menu** (GPIO 5) | メニューを開く | 決定 |
| **play** (GPIO 20) | 再生 ⇔ 一時停止 | 即 PLAY 画面へ戻る |
| **prev** (GPIO 12) | スマート曲戻し(再生開始 3 秒超なら頭出し、未満なら前の曲) | 1 階層戻る(「../ (戻る)」と同じ) |
| **next** (GPIO 16) | 次の曲 | カーソル行のお気に入り ★ トグル(アルバム・お気に入り・履歴・統計の各階層のみ) |

補足:

- 次曲ボタンでの ★ トグルは、アルバム階層で**カーソルが合っている曲**に対して働きます。太字(二度描き)で表示されている行が ★ 済みです
- お気に入りの並べ替え・一括管理は Web 管理画面が便利です(ドラッグ & ドロップ対応)
- リソース画面(RAM/ROM・CPU/温度・バッテリー残量)では **play ボタンでシステム設定に戻ります**
- 音量変更直後 5 秒は PLAY 画面の右端スロットが `VOL: ○○%` 表示になり、その後 `BAT: ○○%` に戻ります

## メニュー遷移図

```text
PLAY 画面 ──[menu]──▶ メニュー(TOP)
                       ├─ ★お気に入り
                       ├─ アルバム
                       │    ├─ 曲ライブラリ再読み込み
                       │    ├─ [再生履歴](最大30曲)
                       │    ├─ [再生統計](総再生時間・累計曲数・TOP3)
                       │    └─ アルバム一覧 ──▶ 曲一覧
                       ├─ 再生設定
                       │    ├─ シャッフル: OFF / ON
                       │    ├─ リピート: OFF / ONE / ALL
                       │    ├─ スリープタイマー: OFF / 30M / 1H / 2H
                       │    └─ 出力先設定: PWM / USBOTG / BT
                       └─ システム設定
                            ├─ 接続設定
                            │    ├─ Wi-Fi設定
                            │    ├─ Bluetooth設定(登録済み / 新規検索)
                            │    └─ APモード: ON / OFF
                            ├─ 電源メニュー(アプリ再起動 / 再起動 / シャットダウン)
                            ├─ GitHubから更新
                            ├─ ライセンス表示
                            ├─ RAM/ROM使用量
                            ├─ CPU使用率/温度
                            └─ バッテリー残量(直近5時間のグラフ)
```

隠し機能(時計画面・EQ)を解放済みの場合、TOP に「時計画面」、システム設定に「隠し機能を削除」が現れます。

## 最初の一歩

1. **音楽を入れる**: Web 管理画面の「DUFSを開く」から `/home/pi/music` へアップロードし、本体メニューの「曲ライブラリ再読み込み」を実行
2. **出力先を選ぶ**: 再生設定 → 出力先設定(PWM: 本体アナログ / USBOTG: USB オーディオ / BT: Bluetooth イヤホン)
3. **再生する**: アルバム → 曲を選択。電源を切る前に再開位置が保存され、次回起動時に復元されます

## Bluetooth イヤホン

1. 接続設定 → Bluetooth設定 → 新規デバイスの検索 → 検索開始(約 8 秒)
2. 表示されたイヤホンを選ぶとペアリングと接続まで自動で進みます
3. 以後はイヤホン側のボタンで **再生/一時停止・次の曲・前の曲** が操作できます(AVRCP 対応機種)
4. 接続が切れた場合は自動で再接続を試行します

Wi-Fi と Bluetooth の同時使用は 2.4 GHz 帯で干渉することがあります。音切れが気になるときは、再生中の大容量 Wi-Fi 通信を避けるか Wi-Fi を OFF にしてください。

## Tips

- **スリープタイマー**: 再生設定 → スリープタイマー。PLAY 画面上部に `T:1H59` 形式の残り時間が表示されます
- **GitHubから更新**: 実行前に画面の全画面更新が入ります。更新中は管理画面と本体の操作ができません
- **無操作 10 秒**: メニュー画面から自動で PLAY 画面に戻ります(省電力・残像対策)
- **充電・残量確認**: バッテリー残量画面(本体)または管理画面のグラフで直近 5 時間の推移が見られます
